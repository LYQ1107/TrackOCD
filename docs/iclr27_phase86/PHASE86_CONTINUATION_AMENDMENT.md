# Phase86 continuation amendment

This amendment repairs deployment and execution contracts without re-registering
the original ten-hour window. The old event-fold-modulo-3 U1 result remains a
diagnostic. The old within-track four-frame RF result remains a diagnostic and
is not called canonical root-of-fragments.

The corrected route trains one support expert on all non-event TRAIN groups,
then one U1 utility gate on all out-of-fold TRAIN metadata, and replays every
positive and negative event with those same frozen models. The registered
thresholds, candidate universe, seed, denominator and sealed boundary remain
unchanged. U2 is pre-authorized if corrected U1 event safety fails; U2 may use
only TRAIN-disjoint validation for configuration selection and must use one
all-TRAIN model for formal event replay. No event result may tune U2.

No DEV+, Q1, public-new or sealed labels are used for training or selection.
